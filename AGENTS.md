# Agent Notes

- Before using local tooling or development environments, read
  [.local/AGENTS.md](.local/AGENTS.md) if it exists.
- Keep tracked files independent of the developer's local setup. Use generic
  names and synthetic addresses in documentation, examples, and tests; exclude
  actual machine identities, local network arrangements, and user-specific
  paths.
- UI text follows [Design](DESIGN.md): help text only where a control cannot
  explain itself, in one short sentence; limits and internals belong in
  [Architecture](docs/ARCHITECTURE.md).
